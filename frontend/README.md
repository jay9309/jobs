# JobOrbit Frontend

React + Vite + Tailwind frontend for the JobOrbit job portal.

## Run

```bash
npm install
npm run dev
```

Frontend: http://localhost:5173

Set `.env` from `.env.example` if the backend is not running on `http://localhost:5000`.

## Design

The homepage and supporting pages use the JobOrbit visual language from the supplied reference:
- white navigation
- navy/blue hero
- rounded search bar
- category chips
- featured jobs
- premium apply-access card
- clean blue/purple accent system
- responsive layouts

The `hero-person.jpg` asset is a cropped visual from the supplied reference image for local development.

Admin mobile sidebar can be expanded later; desktop layout is included in this starter.
